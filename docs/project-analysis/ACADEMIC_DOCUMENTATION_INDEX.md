## Document Governance

The index is a documentation plan, not evidence that every section is implemented. Every completed chapter must identify its sources, distinguish verified implementation from interpretation, and record missing evidence. The certificate page is intentionally excluded because it is an institutional attestation rather than a software-project artifact and was explicitly requested for removal.
